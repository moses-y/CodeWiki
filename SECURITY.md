# Security Policy

This document describes how security is handled for **CodeWiki** (version 1.0.1).
We take the security of CodeWiki and its users seriously and appreciate the
efforts of those who responsibly disclose vulnerabilities to us.

## Supported Versions

Security updates are provided for the following releases of CodeWiki. We
recommend always running the latest available version.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues,
pull requests, or discussions.**

Instead, report them privately using one of the following channels:

1. **GitHub Security Advisories (preferred):** Open a private report through
   the repository's [Security Advisories](https://github.com/yourusername/codewiki/security/advisories/new)
   page ("Report a vulnerability").
2. **Email:** Send details to the maintainers at `security@example.com`
   (replace with the project's official security contact). If possible,
   encrypt sensitive details before sending.

When reporting, please include as much of the following as you can:

- A clear description of the vulnerability and its potential impact.
- The affected version(s) or commit hash of CodeWiki.
- Step-by-step instructions to reproduce the issue.
- Any proof-of-concept code, logs, or screenshots.
- Your assessment of severity and any suggested remediation.

## Disclosure Process

After you submit a report, you can expect the following:

- **Acknowledgement** of your report within **3 business days**.
- An initial **assessment and triage** within **10 business days**, including
  whether the report is accepted, needs more information, or is declined.
- Regular updates on remediation progress for accepted reports.
- Coordination with you on a **public disclosure date** once a fix is
  available. We aim to release fixes for confirmed, high-severity issues
  within **90 days** of confirmation.

We kindly ask that you give us a reasonable opportunity to address the issue
before any public disclosure, and that you avoid accessing, modifying, or
deleting data that does not belong to you while researching.

## Scope

This policy applies to the CodeWiki source code maintained in this repository.
Vulnerabilities in third-party dependencies should be reported to their
respective maintainers, though we welcome notifications so we can update or
patch affected dependencies.

## Recognition

With your consent, we are happy to credit you for responsibly disclosing a
valid security issue once it has been resolved.

Thank you for helping keep CodeWiki and its users safe.
